# Volatility-Modelling-using-Garch-Models
Project Description This project focuses on modelling and forecasting the volatility of Netflix stock returns using GARCH-family models.

## Objective

The aim of this project is to estimate and forecast Netflix stock return volatility using:

- GARCH(1,1)
- EGARCH(1,1)
- GJR-GARCH(1,1)
